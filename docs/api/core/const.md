title: Constants
---

Constants are defined and exposed as:

```ts
import Atipicial from "@atipicial/atipicial-js";
const nativeContractHashes = Atipicial.CONST.NATIVE_CONTRACT_HASH;

import { CONST } from "@atipicial/atipicial-js";
const addrVersion = CONST.DEFAULT_ADDRESS_VERSION;
```

Do refer to the source code for all the constants available.
